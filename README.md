# وين راحت؟ — اعرف فلوسك وين تروح

برنامج عربي لمتابعة مصروف البيت وتنظيم أموره المالية. يعمل في المتصفح ويُثبَّت على الجوال والحاسوب كتطبيق (PWA)، وكل البيانات تبقى على جهازك.

## مبدأ العمل

**سجّل ← شوف وين راحت ← خطّط بالميزانية ← تابع دخلك.**

- **الحساب** مكان المال: النقد، البطاقة، أو أي محفظة إلكترونية. رصيده = رصيد البداية + الدخل − المصروف ± التحويلات.
- **الحركة** ثلاثة أنواع فقط: مصروف، دخل، تحويل بين حسابين. تسجّلها مباشرة، بدون توزيع أموال على محافظ قبل الصرف.
- **الفئة** سبب الصرف (بقالة، فواتير، مواصلات…)، ولها سقف شهري اختياري للمقارنة فقط.
- **مصدر الدخل** (الراتب، الحوافز…) له يوم متوقع. يذكّرك البرنامج حتى تسجّل استلامه.
- **الشهر المالي** يبدأ من يوم تختاره (1–28)، مثلاً يوم الراتب.

## الصفحات

| الصفحة | ماذا تعرض |
|---|---|
| الرئيسية | صرفت هذا الشهر ومن أي دخل، وتيرة الصرف، الدخل المتوقع، الأرصدة، وين راحت فلوسك، آخر الحركات |
| الحركات | بحث وفلاتر، والحركات مجمّعة حسب اليوم. الضغط على أي حركة يعدّلها أو يحذفها |
| ＋ سجّل | مصروف أو دخل أو تحويل في نافذة واحدة، مع «تراجع» بعد الحفظ |
| الميزانية | سقف كل فئة وما صُرف منه وحالته، وإدارة الفئات |
| التقارير | الدخل والمصروف والصافي، التوزيع على الفئات، المقارنة بالشهر السابق، الصرف اليومي، آخر 6 أشهر، PDF وCSV |
| الإعدادات | الاسم ويوم بداية الشهر والعملة، الحسابات، مصادر الدخل، المظهر، النسخ الاحتياطي والاستعادة |

## البيانات والخصوصية

- كل البيانات في تخزين المتصفح على جهازك (`localStorage`). لا خادم ولا مزامنة.
- نزّل نسخة احتياطية JSON كل أسبوع من الإعدادات، واحفظها خارج الجوال.
- **الترقية من الإصدار السابق** (فِرزة/ميزان): تُنقل البيانات تلقائياً عند أول فتح. تبقى النسخة القديمة كما هي، ويمكن تنزيلها من الإعدادات. التفاصيل في [`docs/REDESIGN.md`](docs/REDESIGN.md).

## التطوير

```bash
npm ci            # أدوات التطوير فقط (ESLint)؛ البرنامج نفسه بلا اعتماديات
npm start         # خادم محلي على http://localhost:8080
npm test          # الاختبارات
npm run check     # lint + الاختبارات (تعمل تلقائياً في GitHub Actions)
```

### بنية الكود

| المسار | المسؤولية |
|---|---|
| `src/core/format.js` | العملات، قراءة المبالغ وتنسيقها، التواريخ، والشهر المالي بيوم بداية مختار |
| `src/core/ledger.js` | نموذج البيانات (الإصدار 3): التحقق، الإضافة والتعديل والحذف، الأرصدة، ملخص الشهر، الميزانية، حالة الدخل، الاتجاهات |
| `src/core/migrate.js` | نقل بيانات الإصدار 2، مع التحقق من تطابق الأرصدة |
| `src/app/store.js` | الحفظ المحلي، النقل عند أول فتح، لقطة يومية احتياطية، النسخ والاستعادة |
| `src/app/ui.js`, `icons.js` | المكونات المشتركة: النوافذ، الإشعارات مع التراجع، الحقول، الأيقونات |
| `src/app/main.js` | الحالة، التنقل، شريط الشهر، المظهر، التشغيل |
| `src/app/views/*.js` | الصفحات: الرئيسية، الحركات، نافذة التسجيل، الميزانية، التقارير، الإعدادات، البداية |
| `styles.css`, `fonts.css` | ملف التصميم الوحيد (ألوان الهوية للفاتح والداكن) وخط Readex Pro المحفوظ داخل الموقع |
| `report-pdf.js` | توليد تقرير PDF محلياً |

ملفات `src/core` دوال نقية تعمل في المتصفح وفي Node، وتُختبر مباشرة. الواجهة كلها تحت مساحة الاسم `WR`.

عند تعديل أي ملف JS أو CSS: حدّث `?v=` في `index.html` وفي `sw.js` معاً وغيّر اسم `CACHE`. الاختبار `tests/assets.test.cjs` يتحقق من تطابقهما، و`tests/brand.test.cjs` من الألوان والتباين (4.5:1 على الأقل في الوضعين).
