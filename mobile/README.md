# «وين راحت؟» — تطبيق Android باستخدام Capacitor 8

هذا الغلاف الأصلي يجمع **نفس ملفات الموقع الحالية** في تطبيق Android يعمل دون خادم أو تسجيل حساب. لا يغير الموقع المنشور، ولا يرفع البيانات المالية إلى GitHub.

## المتطلبات

- Node.js 22+، Java JDK 21، Android Studio/SDK 36.
- إعداد هوية التطبيق الحالي: `mobile/capacitor.config.json`. المعرّف المقترح `iq.ammar.weenrahat` **يجب تأكيده قبل أول إصدار منشور**، لأن تغييره لاحقاً يعني تطبيقاً مختلفاً.
- لا تحفظ كلمات المرور أو ملفات التوقيع في المستودع.

## التشغيل المحلي

من جذر المستودع:

```bash
npm ci
npm run check
cd mobile
npm install
npm run check:syntax
npm run web
npx cap add android
npx cap sync android
npm run native:configure
npx @capacitor/assets generate --android --iconBackgroundColor '#F6F2EA' --splashBackgroundColor '#F6F2EA'
npx cap open android
```

من Android Studio استخدم Run على جهاز تجريبي، أو أنشئ حزمة Debug من Build. عند تحديث أي ملف ويب: من مجلد `mobile` نفّذ `npm run web && npx cap sync android` ثم أعد البناء. لا تستخدم `server.url` للإصدار المنشور؛ التطبيق يجب أن يتضمن الأصول محلياً.

يُنشأ مشروع `mobile/android` و`mobile/www` وقت البناء ولا يتم رفعهما إلى GitHub. في GitHub Actions يُبنى ملف APK تجريبي تلقائياً عند فتح PR؛ وتُتاح حزمة AAB الموقّعة عند تشغيل workflow يدوياً وتوفير الأسرار المطلوبة.

## هوية التطبيق

- الاسم: «وين راحت؟».
- الألوان: الأخضر `#0F5E56` والذهبي `#D9A441` والخلفية `#F6F2EA`.
- الشعار الحالي: `icon.svg`؛ يولّد `@capacitor/assets` أيقونات Adaptive وSplash من نسخة SVG نفسها.
- رمز الحزمة المقترح: `iq.ammar.weenrahat`؛ راجع تفرده وملكيته قبل النشر.

## الحفاظ على البيانات

**الموقع وAndroid لا يتشاركان التخزين، حتى على الهاتف نفسه.**

1. من الموقع القديم > الإعدادات > بياناتك > نسخة احتياطية. احتفظ بملف JSON خارج المتصفح.
2. ثبّت نسخة Android، ثم من الإعدادات > استعادة نسخة اختر ملف JSON.
3. قارن أرصدة الحسابات، عدد الحركات، المبلغ الإجمالي والتقرير الشهري **قبل حذف أي نسخة قديمة**.
4. صدّر نسخاً أسبوعية. لا تضع ملفات JSON المالية ضمن المستودع أو Issues.
5. لا تمسح بيانات المتصفح ولا تعِد تثبيت التطبيق قبل التأكد من وجود نسخة سليمة.

نسخة Android تستخدم `localStorage` داخل sandbox خاص بالتطبيق؛ وتُعطّل إعدادات الحزمة النسخ السحابي التلقائي لنظام Android. النسخة المحلية **غير مشفرة بتشفير خاص بالتطبيق**. ملفات JSON/CSV/PDF تُكتب مؤقتاً في Cache ثم تُفتح نافذة Android للحفظ/المشاركة. لا تُعدّ البيانات محفوظة نهائياً إلا بعد اختيار مكان حفظ خارجي؛ وقد تحتوي على معلومات مالية حساسة.
